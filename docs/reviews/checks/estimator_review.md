## 3. Confidence under adaptive power selection

Each batch uses fresh independent Bernoulli shots. Conditioning on the preceding history fixes the next power and its Bernoulli parameter. The fixed-radius Hoeffding bound therefore applies conditionally, uniformly over histories. Averaging and taking a union bound over the deterministic maximum number of batches yields the stated coverage. Adaptive powers do not invalidate that argument. It would fail if a backend pooled old adaptively stopped shots, returned approximate fractional counts, or supplied correlated measurements without an additional theorem.

The confidence planner now checks that its padded logarithm is below 100. In this range, its 10⁻⁶⁰ envelope dominates correctly rounded eighty-digit logarithm and argument-rounding errors. The planner rejects cases outside that declared numerical domain. The count validation now rejects fractional counts and Boolean values. Empty intersections are explicitly labelled failures; the returned zero is an output on the allowed failure event, not a certified zero price. A caller must preserve that status and must charge any repeated run with an appropriate additional confidence and cost allocation.

## 5. Logical quantum premise

I checked the emitted reflection and Grover templates. The uncontrolled template omits a global minus, which does not change shot probabilities. The controlled template correctly supplies that minus with Z on the control. In the control-zero branch the unconditional adjoint/preparation pair cancels; in the control-one branch the controlled reflections produce the specified Grover operator. The clean conjunction work is uncomputed. Reflecting only the financial input, comparison and flag is valid on the established invariant subspace where arithmetic work is zero.

A measurement-assisted evaluator cannot be substituted merely because its basis-state output distribution is correct. It must realise the same logical channel on coherent and entangled inputs, with corrected records proportional to the same logical map and input-independent branch probabilities. Its logical adjoint must be implemented by another verified instrument, rather than by reversing recorded measurements. Without this premise, the amplified Bernoulli probability used in the confidence proof is unproved. The current exact unitary template avoids that issue. Physical shot-probability inaccuracies require a separate fault allocation; a fixed deterministic arithmetic-bias certificate does not cover iteration-dependent noise.
