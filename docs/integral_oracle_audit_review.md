# Independent integral pricing oracle audit

## 1. Whole financial composition

The final frozen financial compiler passes 28 complete graph and architecture fixtures. These cover the integral second-order correction, direct second-order correction and positive first-order correction, both truncated-normal quantile preparation and uniform-box Gaussian likelihoods, and both coherent lookup architectures. Both second-order methods are checked in centred, positive-part and negative-part forms.

A separate integer interpreter, which calls neither graph.evaluate nor Circuit.run, supplies every financial reference value. Exact packed Boolean replay checks 14,336 dirty numerical-output lanes and 14,336 comparison and dirty-flag lanes. Every input register is retained, every scratch wire returns to zero, and the inverse recovers the original dirty target. Every intermediate is checked for unsigned overflow or signed modular ambiguity. Split identities hold exactly for all retained financial input states. Some deliberately coarse direct second-order fixtures clip their centred outputs to zero. Their negative parts then reach the saturated unit endpoint. These outcomes are retained as arithmetic-composition evidence, rather than presented as attained financial accuracy or favourable performance.

The complete counted profiles equal the independently expanded whole circuit primitive counts. Their literal T dependency depths match the separate emitted sequence replay; their serial composition depth caps and qubit allowances enclose the full fixtures. Argument aliasing, including the square of a shared register, is retained in block emission and independently checked. The exact dirty-target XOR property also establishes the intended coherent logical map when combined with the separately proved phase-correct primitive decompositions.

## 2. Primitive and scalar checks

A nonmonotone interpolation fixture checks 4,352 input and dirty-target lanes, including both decreasing cells and the exact dyadic upper endpoint. The declared integer convention is base plus or minus floor of the positive difference magnitude times the fractional remainder. Its decreasing branch rounds towards the base. The one-unit arithmetic allowance therefore applies to either direction. Both lookup architectures retain four actual lookup invocations across this fixture's computation and cleanup.

Sixteen small expanded lookup isometries are checked on every clean-work basis column, including arbitrary dirty output values and enabled branches. Their amplitudes match the exact reference permutation without a relative phase. Coherent linear combinations and literal physical adjoints also pass the numerical diagnostics. These matrix checks support the existing algebraic phase proof; they do not replace it. A further 44,184 comparison lanes check every integer threshold, including zero, the exact unit endpoint and both dirty flags. The zero-normalisation case returns a centred half and zero split parts, as required.

The independent scalar archive audit checks all 60 retained certificates and 242,747 nodes at 416-bit Arb precision. Inverse quantile intervals are checked by CDF bracketing, independently of erfinv. Gaussian derivative nodes use the equivalent phi-prime expression. Capped payoffs and first derivatives use a separate closed-form expression. Exact rational checks reconstruct all nodal and interpolation error allowances. Compact JSON record keys, the gzip checksum and all links from the 81 graph assessments are verified. This is a scalar and provenance audit. A passed graph domain guard is not by itself an attained monetary tolerance.

## 3. Production profiles

All 126 retained production profiles pass fresh block emission and independent gate accounting. There are 312 unique emitted blocks, including the comparison block, with 2,488 retained production node basis paths checked. The audit reconstructs every argument-width and alias pattern, scalar table checksum, actual primitive count, literal seven-T dependency depth, lookup invocation count, serial cap and peak-qubit composition. Each complete preparation includes the financial body, its clean inverse, the flag comparison and every uniform Hadamard. Actual expanded block tape hashes are retained. This evidence does not exhaust the production tensor grid; the whole small circuits and the established arithmetic proof supply the complementary correctness checks.

The audit scope is an ideal logical quantum circuit and a certified finite numerical function. No physical quantum experiment, market validation, literature priority or practical quantum advantage follows from these checks.

## 4. Reproducibility

The audit scripts are in checks/audit_integral_value_oracle.py, checks/audit_integral_production_profiles.py, checks/audit_integral_scalar_certificate.py and checks/audit_estimator_extension.py. They use the support modules checks/integral_audit_support.py and checks/integral_phase_support.py. The whole financial and scalar archive scripts require python-flint and NumPy. I used the existing certification virtual environment with its existing Python 3.13 NumPy installation exposed through PYTHONPATH; no package was installed. The estimator audit can use the bundled NumPy runtime. All scripts accept a project root or explicit retained profile path and preserve the result hashes.

No main repository file or Git state was changed during this independent audit.
