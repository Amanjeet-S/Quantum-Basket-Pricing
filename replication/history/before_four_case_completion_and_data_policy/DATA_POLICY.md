# Data policy

## 1 Existing access

I use free public sources and existing authorised institutional or LSEG access at no additional cost. OptionMetrics and new paid datasets are excluded. Demonstration files do not constitute independent empirical validation.

## 2 Repository contents

The GitHub repository is private. Raw LSEG exports, credentials and reconstructible transformations remain excluded from Git regardless of visibility. Current experiments use stipulated synthetic data only. Derived findings require a disclosure review before any wider release.

## 3 Source evidence

I retain version and section records for academic material. Publisher PDFs and the full supplied attachments are not uploaded. Local attachment hashes identify the reviewed material without publishing it.
