# Project development priorities

## 1 Purpose and retained research

I use the project primarily to demonstrate mathematical and computational preparation for quantitative finance graduate study. The [preparation audit](PREPARATION.md) maps proofs/code to entry requirements and published modules, distinguishing applied depth from broader foundation gaps. A new quantum theory, publication or physical advantage is not required for this purpose. I must still explain the mathematics, implement the methods and interpret the financial comparisons accurately.

I retain the classical no-arbitrage financial law and quantum pricing investigation. The [working paper](generalisation_proofs.tex), [supporting index](supporting_proofs_index.md) and [originality assessment](originality_assessment.md) govern the checked results and literature boundaries. Frozen protocols, failures, comparative costs and historical source versions remain preserved.

## 2 Next preparation development

The first priority is a tractable capped-GBM pricing companion using the existing payoff and synthetic-data policy. I should connect self-financing replication, the Black–Scholes PDE and the martingale/call-spread price, state terminal/boundary conditions, implement one finite-difference solver and compare analytic/PDE/Monte Carlo prices and sensitivities. Grid, truncation, arithmetic and sampling errors must remain distinct. This is planned work, not a completed result.

A concise L2 conditional-expectation/variance argument would clarify the existing conditioning and control variates. Subsequent estimation and constrained hedging/portfolio exercises should answer specific financial questions. Physical-return means must not be substituted for the risk-neutral drift. Broader real analysis/probability belongs in assessed coursework and independently solved preparation exercises. An original small C++ pricing implementation would address Oxford-specific language preparation.

## 3 Optional scientific extension

The proved sharp Gaussian component moduli remain unselected in the registered resource costs. If I pursue their cost contribution, I must supply every applicable raw-payoff, numerical conditional-price and shared-threshold rival with the same price-independent information, register exact uniform-gap/root/error/selection rules before outcomes and rebuild complete financial allowances and cancellation-aware confidence charges. Fixed-gap bounds must not become unproved uniform envelopes. All rejected and zero/negative gains remain visible.

A smaller isolated derivative coefficient is not a complete cost improvement. If complete outcomes remain unchanged, I retain that result without presenting the refinement as a cost contribution. This optional novelty question no longer blocks the mathematical-preparation objective.

## 4 Completion and presentation

Completion requires a coherent financial question, checked derivations, readable reproducible pricing comparisons, honest preparation evidence and claims matched to retained results. The paper should keep essential structure in the main text and detailed derivations in appendices/support. The first repository example should explain a financial price and its error before specialised gate counts.

The current paper remains a working paper. The [previous plan](history/before_preparation_review/quantum_method_redesign.md) retains the earlier originality-led priority.
