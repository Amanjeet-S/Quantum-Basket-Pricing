# 1. Source and software record

I consulted the published Ross and Selinger paper on 7 October 2026 through the publisher PDF at <https://www.rintonpress.com/xxqic16/qic-16-1112/0901-0953.pdf>. The material actually read comprised the introduction and Sections 7.1 and 9, including Definition 13, Lemmas 9 and 10, Definition 15 and Lemma 16. The publication is Ross, N.J. and Selinger, P. (2016), ‘Optimal ancilla-free Clifford+T approximation of z-rotations’, *Quantum Information and Computation*, 16(11–12), 901–953. DOI: <https://doi.org/10.26421/QIC16.11-12-1>. The publisher final version was consulted, rather than attributing a preprint reading to the published text. These sections support the operator-norm synthesis convention and the requirement to retain scalar phases. I do not invoke its conditional near-optimality theorem to assert that the retained tapes are optimal.

I consulted the official pygridsynth repository README at <https://github.com/quantum-programming/pygridsynth>, its usage, installation, licence and reference sections. I inspected the unmodified installed 1.2.0 release source, specifically `gridsynth.py` for its proposed rotations and precision configuration, `quantum_gate.py` for matrix-product order, scalar W gates and the Clifford matrices, and `config.py` for the seed and `up_to_phase` setting. The retained manifest records SHA-256 digests of every source module of the generator. This release is distributed under the MIT licence. It was acquired from the free public Python package registry solely into a temporary directory. Existing user environments and project dependencies were not changed.

The regeneration environment uses pygridsynth 1.2.0, mpmath 1.4.1, 100 decimal digits, a fixed seed of 1729, requested operator tolerance 2^-20, and `up_to_phase=False`. The exact pi/4 tape and sufficiently small identity replacements are declared separately. The resulting tapes are checked by a different implementation using the existing python-flint 0.9.0 environment at 384 bits. The production profile API requires neither pygridsynth nor mpmath because it reads retained tapes and their independent rational certificates.

The repository current release 2.0.0 was inspected but was not used for any retained tape: its synthesis import reaches optional mixed-synthesis optimisation libraries. I selected the unmodified smaller 1.2.0 release for the retained computation. An initial general dependency acquisition was cancelled before completion; the retained tapes use only the separately acquired synthesis package and mpmath. No paid service, financial data or private entitlement was used.

# 2. Reproduction and interpretative limits

I run `generate_qft_rotations.py` in an isolated temporary environment containing the pinned synthesis packages. This creates `results/qft_rotation_tapes.json`. I run `certify_qft_rotations.py` and `audit_qft_synthesis.py` in the existing python-flint environment. The production standard-library command `python3 qft_synthesis.py` creates all 32 resource profiles. The scripts accept a `QBP_SYNTHESIS_VENDOR` environment path for an isolated generator runtime, otherwise use a sibling `synthesis_vendor` directory. Installing the packages is optional for regeneration; the retained gate products and certificates can be replayed without synthesis packages.

The small inverse DFT checks use wire 0 as the most significant bit. A benchmark with a least-significant-bit convention must relabel the wires and its result interpretation consistently. The known final Fourier scalar is harmless for an uncontrolled Fourier operation. This is not permission to ignore the scalar sign of a controlled Grover operator.
