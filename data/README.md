# Data and reference inputs

## 1. Permitted public material

[Public Sobol reference material](public/sobol/) retains the existing direction numbers, implementation and source licence. It is a numerical reference input, not an empirical financial dataset. Current financial experiments use synthetic model inputs; their retained outputs are in [results/](../results/).

## 2. Restricted observations

No raw LSEG observations or restricted transformed inputs are distributed here. The [data policy](../docs/DATA_POLICY.md) records the university guidance on individual research use, attribution, permitted summaries and deletion of underlying observations at completion. A private repository does not override those restrictions.

Any local restricted inputs must remain in ignored storage and must not be copied into a reproduction workspace for distribution. Further acquisition is limited to free sources or existing authorised institutional access at no additional cost.
